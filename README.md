# RAG_app
# 📄 RAG PDF Chatbot

A Retrieval-Augmented Generation (RAG) chatbot built with **Streamlit**, **LangChain**, **FAISS**, and **OpenRouter API**. Upload a PDF and ask questions based on its content. The chatbot retrieves relevant information from the document before generating an answer, reducing hallucinations and improving accuracy.

## 🚀 Features

- 📄 Upload PDF documents
- 🔍 Intelligent document chunking
- 🧠 Vector search using FAISS
- 🤖 AI-powered question answering with OpenRouter
- 📚 Displays retrieved source chunks
- 🌐 Deployable on Railway or Hugging Face Spaces

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- PyPDF
- OpenRouter API
- OpenAI Embeddings
